# Skill: Word 论文 / 开题报告转学术 PPT 大纲与高级排版规划引擎 (`word-to-ppt-outline/v2`)

> 模型无关（Model-Agnostic）底层核心规范：无论底层切换为本地零幻觉引擎、DeepSeek、Qwen、Gemini、OpenAI 或 Hosted Pro，均须严格遵循本 Skill 将科研文稿转化为 **小红书 / 顶刊答辩级多维信息图版式 + 2D/3D 分子可视化** 的结构化 JSON 大纲。

## 一、大纲叙事结构规范（按场景自适应）

1. **学位答辩 / 中期考核（`defense` / `midterm`）**：
   - 第 1 部分：**研究背景与科学痛点**（临床/工艺瓶颈、耐药问题、现有手段局限）
   - 第 2 部分：**分子设计与研究方案**（先导骨架、药效团改造逻辑、研究路线与实验设计）
   - 第 3 部分：**核心结果与机制验证**（活性/选择性/PK/收率对照、3D 结合构象或反应机理）
   - 第 4 部分：**创新总结与后续规划**（核心突破点凝练、风险/策略矩阵与未来计划）
2. **组会汇报（`group_meeting`）**：
   - 聚焦近期实验目标 → 结构改造或条件筛选 → 实测数据对比 → 问题分析与下周计划。
3. **文献综述（`literature_review`）**：
   - 按领域演进 → 代表性先导骨架对比 → 构效关系与结合模式 → 领域空白与启示组织。
4. **开题报告安全门禁（`is_proposal = true` 时强制执行）**：
   - **严禁虚构**尚未测得的 `IC50`、收率、药代参数或动物实验结论；重点提炼立题依据、科学假说、拟合成路线及可验证指标。

## 二、文本凝练与信息图表化原则

- **零幻觉数据**：所有数值、化合物代号（如 `Osimertinib`、`YJ-402`）必须严格源自原文段落或提取出的 Word 表格，禁止编造指标。
- **拒绝整段照抄**：将 Word 段落拆解为“结论先行句 + 结构化卡片/时间轴/对比组/指标卡”，绝不整段文字平铺直叙。
- **短标题原则**：每页 `title` 控制在 18 个汉字以内，表达“结论或核心主题”而非泛泛的“研究内容”。
- **一句话结论**：`takeaway` 控制在 38 个汉字以内，必须完整陈述该页核心结论。
- **要点精简**：`bullets` / `insights` 放 2–4 条高信息密度短句（每条 ≤ 26 字），实验细节写入 `speaker_notes`。

## 三、小红书 / 顶刊答辩信息图版式库（13 种 `layout_id` 语义路由表）

禁止连续两页使用相同 `layout_id`，请根据本页内容语义精准匹配以下 13 种高密度矢量排版模板：

| `layout_id` | 版式视觉骨架 | 最适用学术汇报内容 |
| :--- | :--- | :--- |
| `bg_top_summary_3box` | 顶部目标横幅 + 三框左痛点中结构右突破 | **研究背景与立题依据**（宏观背景 + 核心切入） |
| `pain_points_left_arrows` | 左侧箭头痛点列表 + 右侧分子对照窗 | **临床/工艺痛点拆解**（既有手段局限性分析） |
| `dual_compare_cards` | 顶部总结带 + 左右双栏 + 居中 `VS` 圆标对比 | **国内外现状 / 传统方法 vs 本研究突破** |
| `tri_column_showcase` | 顶部三栏递进立柱 `01/02/03` + 下方宽幅大图与指标 | **三大研究亮点 / 理论与实践意义 / 多模块成果** |
| `lit_overview_dual_card` | 左侧双分子演进对比框 + 右侧文献档案指标卡 | **文献综述 / 先导骨架演进与 SAR 对比** |
| `hub_spoke_radial` | 左侧三层同心圆环焦点 + 虚线连接右侧三阶要点 | **总体研究思路 / 核心体系构建 / 课题总览** |
| `quadrant_2x2_matrix` | 左侧 2×2 四象限策略矩阵 + 右侧分子与核心 KPI | **四维创新点 / 风险评估 / 多靶点协同策略** |
| `timeline_chevron_flow` | 顶部四阶递进箭头时间轴 + 左大图右里程碑卡 | **研究进度 / 实验流程步骤 / 阶段推进计划** |
| `roadmap_layered_matrix` | 三层分阶横向矩阵（目标/路线/指标）+ 右闭环链 | **开题技术路线图 / 多阶段研究方案总览** |
| `mechanism_3col_flow` | 三栏联动：左药效团 + 中虚线 3D 构象 + 右优势链 | **作用机制 / 3D 结合口袋 / 催化循环阐述** |
| `fig_left_3step_chain` | 左侧大图展示区 + 右侧三阶递进链式解读 | **关键表征结果 / 逐步机制验证与总结** |
| `vs_center_wing` | 中央聚焦框 + 左右双翼对称指标对撞与引线 | **正反对照 / 关键参数前后优化幅度对比** |
| `data_dashboard_table` | 左 3 大 KPI 瓷砖 + 横向指标对比条 + 右三线表与策略卡 | **实测药代/活性/收率定量数据与 Word 表格** |

## 四、2D / 3D 分子结构式精确选择规则

每一页内容均需从原文提取的化合物或 SMILES 中选出 1 个代表分子并匹配渲染风格：
- **2D 结构式（`visual_mode: "2d"`）**：背景对照药物、先导骨架优化、取代基修饰、构效关系（SAR）、反应产物对比。
  - `visual_style`：`acs1996`（标准黑线 · 杂原子着色）、`minimal_mono`（纯黑极简 · 全黑线稿）、`nature_burgundy`（期刊单色 · 绛红手绘）、`jacs_terracotta`（期刊单色 · 砖红印刷）、`shaded_scaffold`（重点标注 · 环骨架填色）、`reactive_spot`（重点标注 · 反应位点蓝斑）
- **3D 结构式（`visual_mode: "3d"`）**：立体构象、靶点口袋结合、非共价相互作用、刚性骨架空间取向、分子对接。
  - `visual_style`：`ball_stick`（球棍模型 · 经典灰碳）、`pymol_neon_green`（球棍模型 · PyMOL 亮绿）、`metallic_studio`（球棍模型 · 高光金属）、`stick_clean`（棒状模型 · 纯化学键）、`spacefill_cpk`（空间填充 · 范德华球）
